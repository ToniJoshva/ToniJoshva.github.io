# CodeAlpha Flashcard Quiz App

A responsive web app built with HTML, CSS, and vanilla JavaScript for a CodeAlpha internship task.

## Run it
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. For the Flashcard Quiz, cards are saved in the browser's localStorage.

## Files
- `index.html` — page structure
- `style.css` — responsive design and styling
- `script.js` — app interactions and functionality

## Before submitting
- Test the app in your browser.
- Take screenshots and record a short walkthrough video.
- Create a GitHub repository named according to CodeAlpha's instructions (for example, `CodeAlpha_Flashcard_Quiz_App`).
- Upload the full project folder and submit using the form shared by CodeAlpha.
